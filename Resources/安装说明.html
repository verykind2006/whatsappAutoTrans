autoTrans 安装说明

autoTrans 贴在 WhatsApp 旁边：对方发来外语，自动显示中文；你打中文，翻译后发到 WhatsApp。

需要什么

  • 苹果芯片的 Mac（M1 / M2 / M3 / M4…），系统 macOS 14 或更新。
    （看法：左上角苹果菜单 → 关于本机，「芯片」一栏写着 Apple M…）
  • 已经装好并扫码登录的 WhatsApp 桌面版（App Store 里的 WhatsApp）。
  • 一个翻译用的 API key（例如 Anthropic Claude 的 key，以 sk-ant- 开头）。找给你这个程序的人要。

第 1 步：拖进「应用程序」

把 autoTrans 图标拖到旁边的 应用程序 文件夹上。然后可以把这个窗口关掉、在访达左边把「autoTrans」磁盘推出。

第 2 步：第一次打开

到「应用程序」里双击 autoTrans。

因为这个程序没有在苹果那里付费登记，第一次打开时 macOS 会拦住，说「无法验证」或「Apple 无法检查其是否包含恶意软件」。这是正常的，按下面做一次就好：

  1. 在提示框里点 完成（不要点「移到废纸篓」）。
  2. 打开 系统设置 → 隐私与安全性，往下翻到「安全性」那一段。
  3. 能看到「已阻止 autoTrans…」，点旁边的 仍要打开，输入电脑密码。
  4. 再双击 autoTrans，弹框里点 打开。以后就不会再问了。

第 3 步：跟着设置向导走

  1. 读取权限（完全磁盘访问权限）：用来读 WhatsApp 的聊天记录（只读，不改）。按向导里的按钮打开系统设置，把 autoTrans 的开关打开。打开后可能需要点向导里的「重新打开 autoTrans」。
  2. 发送权限（设备控制和数据访问）：用来把翻好的消息填进 WhatsApp 并点发送。同样在系统设置里把 autoTrans 打开。只看不发的话可以跳过。
  3. 翻译方式：选「联网模型」，服务商选 Anthropic，粘贴 API key，点「验证并保存」。看到 ✓ 就好了。

之后 macOS 会问「autoTrans 想给你发送通知」，点 允许——这样对方来消息时，屏幕右上角会弹出中文翻译。

怎么用

  • 左边点一个聊天，右边就是中文翻译（下面带原文）。
  • 底部打中文 → ⌘+回车 翻译 → 核对（「意思是」那行是译文再翻回中文，方便你检查）→ 再按 ⌘+回车 发送。
  • 给新号码发：左上角「新消息」，填带国家码的号码（如 +34 600 123 456）。
  • 字太小或太大：⌘ + 放大，⌘ - 缩小，⌘ 0 还原。
  • WhatsApp 要一直开着并登录；autoTrans 也要开着才能收到提醒。

隐私

  • API key 只存在这台电脑：~/Library/Application Support/autoTrans/keys.json（只有当前用户能读）。
  • 需要翻译的消息会发给你选的翻译服务（如 Anthropic）。不翻译的内容不会发出去。
  • autoTrans 不改 WhatsApp 的程序和数据，只在旁边读、在旁边发。

卸载

  1. 退出 autoTrans，把「应用程序」里的 autoTrans 拖到废纸篓。
  2. 在访达按 ⇧⌘G，输入 ~/Library/Application Support/autoTrans，把这个文件夹删掉（里面是 key 和翻译缓存）。
  3. 系统设置 → 隐私与安全性 →「完全磁盘访问权限」和「设备控制和数据访问」里，把 autoTrans 删掉。
